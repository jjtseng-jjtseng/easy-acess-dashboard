# Dashboard

A personal dashboard that tracks your most used apps and websites along with the time. It centralizes every task you might need to do. It'll give you reccomendations at the times you usually needs them. Perfect for organization and time keeping.

Two versions are available--one with time keeping, one without (I reccomend the one with time keeping)

## Run

```
python dashboard_time.py             # starts actual page
pythonw dashboard_time.py --no-open  #background reader
```

Runs on windows using python3.

GitHub Releases provides a Windows x64 ZIP. Use both the exe and the other folder besides it for functionaility.
Data doesn't leave your computer for privacy reasons. (it would be unideal for me to have a server of all your personal info)

## Tracking details
- **Sites** --Tracks the past 45 days of Chrome history and uses the favicon for the website icon.
- **Apps** --Listner tracks and looks ever 5 min startingn from the terminal command.
